# Arduino Multifunctionele Klok en Timer

Dit is een Arduino-project dat een LCD-scherm (I2C) combineert met een analoge joystick en LED-output om te functioneren als een actieve tijdmeting (uptime-klok), een willekeurige opstartgroet en een instelbare timer.

## functies
* **Opstartscherm:** Toont een willekeurige groet of statusmelding gekozen uit een lijst bij het opstarten[cite: 1].
* **Uptime Klok:** Houdt bij hoe lang het systeem actief is in uren, minuten en seconden[cite: 1].
* **Timer Module:** Een instelbare timer die na afloop een zoemer/LED (op pin 8) aanstuurt[cite: 1].
* **Joystick Besturing:** Navigeer door menu's en pas de timerwaarden aan (+1 minuut, +5 minuten, +10 seconden) met behulp van een analoge joystick[cite: 1].
